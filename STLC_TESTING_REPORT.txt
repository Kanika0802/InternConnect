1. PROJECT OVERVIEW
================================================================================

Project Name:       InternConnect
Description:        A comprehensive college placement management system designed
                    to facilitate and streamline the internship and job placement
                    process for students and admins.

Technology Stack:
  • Frontend:       React 18, Tailwind CSS, Chart.js
  • Backend:        Node.js, Express.js
  • Database:       MongoDB (Mongoose)
  • Authentication: JWT + bcryptjs
  • Email Service:  Nodemailer (SMTP)
  • File Upload:    Multer (CSV, Excel, PDF support)
  • Deployment:     Vercel (Frontend), Render (Backend)

Key Modules:
  1. Authentication & Authorization
  2. Student Management
  3. Opportunity Management (Jobs/Internships)
  4. Application Management
  5. Analytics & Reporting
  6. Announcements & Notifications
  7. Audit Logging
  8. Admin Dashboard

4. TEST STRATEGY & DESIGN
================================================================================

4.1 Test Design Approach

Test Case Design Techniques:
  1. Boundary Value Analysis (BVA)
     - CGPA: 0, 0.01, 4.99, 5.0, 10.0, 10.01
     - Password: 0 chars, 5 chars, 6 chars, 100 chars
     - Student count: 1, 500, 1000, 10000

  2. Equivalence Partitioning (EP)
     - Valid students vs Invalid students
     - Active opportunities vs Closed opportunities
     - Eligible applications vs Ineligible applications

  3. Decision Table Testing
     - Login: valid/invalid credentials + active/inactive account
     - Application: eligible/ineligible + application exists/not exists

  4. Use Case Testing
     - Complete user journeys
     - Exception handling
     - Alternative flows
